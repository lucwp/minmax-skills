# Content consistency contract

Run this pass page by page and then across the whole proposal.

## Single-carrier rule
Within one page, each important fact, status, metric, date, recommendation, or commercial total should have one primary visual carrier. Functional navigation may repeat section names; body content should not repeat itself for emphasis.

Examples:
- If a badge says `RECOMMENDED`, the option title should not also say “Recommended”.
- If the headline states the core outcome, the first paragraph should advance the argument rather than paraphrase it.
- If a timeline names four phases, do not repeat the same four names in a neighboring list unless the list adds materially different information.

## Cross-page rules
- Summary totals must match detailed totals.
- Scope names must match investment names.
- Optional/future work must never look contracted.
- Dates, terms, quantities, and units must be consistent.
- A metric should retain the same definition and source throughout.
- A recommendation should not change between summary, investment, and next-step pages without explanation.

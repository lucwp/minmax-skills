# Sources, Credits, and Provenance

## What this package is

**MinMax Business OS (`minmax-business`) is an original Mixture-of-Experts orchestration layer synthesized from the strongest public business-skill architectures identified during research.**

It does not claim authorship of the external frameworks, methods, or source skills credited below. The router is designed to coordinate specialist skills rather than silently copy or rebrand them.

No third-party skill repository is vendored wholesale in this package. Attribution here records research provenance and architectural influence. When future MinMax functional packages incorporate or adapt third-party material more directly, preserve the original repository attribution and applicable license in that package as well.

## Attribution policy for future MinMax packages

When adding or compiling specialist business packages:

1. Record the original creator and repository.
2. Preserve the source license when third-party code or substantial text is redistributed or adapted.
3. Distinguish original MinMax orchestration from adapted framework content.
4. Prefer linking to upstream source material over copying it when the runtime can retrieve it.
5. Never remove authorship notices from third-party material.
6. Keep a source-to-capability map so future maintainers can trace why each architecture was selected.
7. If upstream content changes materially, re-evaluate the adapted behavior rather than assuming parity.
